# Changelog

All notable changes to ShiftAble will be documented in this file.

## 0.1.0

Initial release of ShiftAble.

### Added

- Local-first WCAG 2.2 accessibility scanning in Visual Studio Code
- Motor accessibility persona checks
- Visual accessibility persona checks
- Vestibular and cognitive accessibility persona checks
- `A11y: Scan Current File` command
- `A11y: Scan with Jira Spec…` command
- `A11y: Clear Diagnostics` command
- VS Code Problems panel integration
- Editor diagnostics and hover information
- Quick Fix support
- Accessibility sidebar
- Status bar integration
- Bundled accessibility engine for standalone use
- Support for HTML, JavaScript, JSX, TypeScript, TSX, CSS, SCSS, and SVG
- Local `.vsix` packaging and installation workflow
- IBM Bob 2.0 MCP integration through `a11y_scan`
- GitHub Pull Request accessibility workflow support
